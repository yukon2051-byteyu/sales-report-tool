# 売上データ集計ツール

店舗ごとに届く売上ファイル（CSV・Excel）をまとめて読み込み、**店舗別・カテゴリ別・月別**に集計して Excel レポートを自動で作成する Python ツールです。

> 掲載しているデータ（店舗名・商品名・金額など）はすべて架空のものです。

---

## 解決したい業務課題

複数店舗をもつ小売業で、毎月行う売上集計の業務を想定しています。

| | 手作業の場合 | このツールを使う場合 |
|---|---|---|
| 作業内容 | 各店舗のファイルを開き、1つのシートにコピー＆ペーストしてから、ピボットテーブルで集計する | ファイルをフォルダに置いて、コマンドを1回実行する |
| 所要時間（想定） | 店舗数・月数に応じて増える（例：30分程度） | 数秒 |
| ミス | 貼り付け漏れ・二重貼り付け・計算式の崩れが起こりうる | 同じ手順で毎回処理するので、転記ミスが起きない |
| 入力ミスの発見 | 気づきにくい | 空欄・マイナス値・金額の不一致を、ファイル名と行番号つきで警告する |

※ 所要時間は想定の値です。実際に測ったものではありません。

## 主な機能

- **複数ファイルの一括読み込み**：フォルダ内の `.csv` と `.xlsx` をまとめて読み込み、1つの表に結合する
- **3つの切り口で集計**：店舗別・カテゴリ別・月別に、売上合計と数量合計を計算する
- **Excel レポートの出力**：集計結果を4つのシート（店舗別／カテゴリ別／月別／全データ）に分けて保存する。見出しの装飾・3桁区切り・見出し行の固定で見やすく整え、ファイル名にはデータの期間を入れる（例：`売上集計_2026-09_2026-10.xlsx`）
- **入力データのチェック**：入力ミスが疑われる行を警告する
- **分かりやすいエラーメッセージ**：よくある失敗の原因と対処方法を日本語で表示する

## 動作環境

- Windows 10 で動作を確認
- Python 3.15
- 使用ライブラリ：pandas（集計）、openpyxl（Excel の読み書き）、pytest（テスト）

## インストール

```powershell
# 1. リポジトリを取得する
git clone <このリポジトリの URL>
cd <フォルダ名>

# 2. このプロジェクト専用の仮想環境を作る
python -m venv .venv

# 3. ライブラリをインストールする
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## 使い方

1. `input/` フォルダに売上ファイル（`.csv` または `.xlsx`）を置きます。
2. 次のコマンドを実行します。

```powershell
.\.venv\Scripts\python.exe sales_tool.py
```

3. `output/` フォルダに集計結果の Excel ファイルが作られます。

読み込むフォルダや保存先を変えたい場合は、次のように指定します。

```powershell
.\.venv\Scripts\python.exe sales_tool.py --input D:\売上データ --output D:\集計結果
```

## 入力データの形式

1行目は見出しとして、次の7列が必要です（列の順番は自由で、ほかの列があっても問題ありません）。

| 日付 | 店舗名 | 商品名 | カテゴリ | 単価 | 数量 | 金額 |
|---|---|---|---|---|---|---|
| 2026-09-01 | 東店 | ノートA | 文具 | 200 | 5 | 1000 |

- CSV は **UTF-8**（BOM の有無はどちらでも可）で保存してください。Excel で保存するときは「CSV UTF-8（コンマ区切り）」を選びます。
- Excel ファイルは1枚目のシートを読み込みます。
- Excel でファイルを開いている間にできる一時ファイル（`~$` で始まる名前）は、自動で読み込みの対象外になります。

## エラーと警告

| 状況 | 動き |
|---|---|
| 入力フォルダがない／ファイルが1つもない | エラーメッセージを表示して終了 |
| 必要な列が足りない | どの列が足りないかを表示して終了 |
| CSV が UTF-8 ではない（Shift_JIS など） | 保存し直す方法を案内して終了 |
| 出力ファイルを Excel で開いたまま実行した | ファイルを閉じてから再実行するよう案内して終了 |
| 空欄・読み取れない値・マイナス値・金額 ≠ 単価×数量 | ファイル名と行番号つきで警告し、処理は続ける |

エラーで終了したときは終了コード `1` を、正常に終了したときは `0` を返します。

## テスト

```powershell
.\.venv\Scripts\python.exe -m pytest -v
```

pytest による自動テストが16件あります。

- ファイルの検索・読み込み・結合
- 店舗別・カテゴリ別・月別の集計
- Excel の出力（シート構成・ファイル名）
- エラー処理（フォルダなし・列不足・文字コード違い・ファイルなし）とデータチェック
- サンプルデータの集計結果が、手で計算した値と一致するか

テスト用のデータはテストの中で一時フォルダに作るので、`input/` と `output/` には影響しません。

## 処理の流れ

```
input/ のファイルを探す（find_input_files）
  ↓
1ファイルずつ読み込む（load_file）… 列の確認、日付・数値の形式をそろえる
  ↓
入力ミスをチェックする（check_data）
  ↓
1つの表に結合する（load_all）
  ↓
店舗別・カテゴリ別・月別に集計する（summarize_by_*）
  ↓
Excel に出力する（write_report）
```

## 開発の進め方

AI コーディングアシスタントの [Claude Code](https://claude.com/claude-code) を活用し、次の方針で開発しました（詳しくは [CLAUDE.md](CLAUDE.md) に記載しています）。

- **小さな機能単位で進める**：「CSV を1つ読む → 複数を結合する → 店舗別に集計する → …」と1機能ずつ実装し、その都度コミットした。コミット履歴から、開発の流れを順に追えるようにしている
- **正解を先に決めて確認する**：サンプルデータの集計結果を先に手で計算し、ツールの出力と一致することを毎回確認した。最終的に、この確認を自動テストにした
- **架空のデータだけを使う**：実在する企業や個人の情報は使っていない
